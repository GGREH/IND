## 🚀 Виконання вимог Етапу 1

### 1. UI/UX концепція для 3 типів пристроїв (Desktop, Tablet, Mobile)
Розроблено макети та архітектуру для трьох типів екранів із дотриманням модульної сітки:
- **Комп'ютер (Desktop, > 992px):** Повнорозмірна шапка з навігацією у рядок, 3-колонкова сітка карток (`grid-3`), горизонтальний Hero-блок.
- **Планшет (Tablet, 768px - 992px):** 2-колонкова сітка карток, компактні відступи, адаптований підвал.
- **Телефон (Mobile, < 768px):** 1-колонкова сітка (вертикальний стек), вертикальне навігаційне меню, повна адаптивність без горизонтального скролу.

### 2. Прототипи 4 обов'язкових сторінок сайту
1. **[`index.html`](index.html) — Головна сторінка:** Банер (Hero) з фірмовим борщем, блок переваг, вітрина популярних страв, блок про атмосферу закладу.
2. **[`menu.html`](menu.html) — Меню:** Розподіл страв за категоріями («Борщі та перші страви», «Вареники та галушки», «Основні страви») із цінами, грамовками та описом інгредієнтів.
3. **[`about.html`](about.html) — Про нас:** Історія виникнення ідеї, значення назви («Жито» — традиції, «М'ята» — свіжість та колір `#98FB98`), принципи роботи та шеф-кухар.
4. **[`contacts.html`](contacts.html) — Контакти:** Форма онлайн-бронювання столика з валідацією полів під час введення (ім'я, телефон, дата, час, кількість гостей), адреса закладу в Києві, телефон, години роботи.

### 3. Базова HTML-структура та CSS
- **Семантичний HTML5:** використано теги `<header>`, `<nav>`, `<section>`, `<footer>`.
- **CSS-змінні (`:root`):** палітра кольорів винесена у змінні (`--color-primary: #98FB98`, `--color-primary-dark`, `--color-text`, `--color-bg` тощо) у модульному файлі [`css/variables.css`](css/variables.css).
- **Сітка (Flexbox & Grid):**
  - Окрема модульна таблиця [`css/grid.css`](css/grid.css) містить базовий reset, контейнери та сітки (`.grid-2`, `.grid-3`, `.grid-4`).
  - Flexbox використано для шапки, навігації, кнопок та карток.
  - CSS Grid (`display: grid`) використано для сітки страв та інформаційних блоків.
- **Компоненти та оформлення:** файл [`css/style.css`](css/style.css) містить стилізацію шапки, кнопок, карток, декоративного орнаменту вишиванки та форми валідації.
- **Адаптивність:** винесена в окремий модуль [`css/responsive.css`](css/responsive.css) із медіа-запитами (`@media`) для планшетів та смартфонів.
- **Без JavaScript:** на першому етапі реалізовано виключно розмітку та стилі. Інтерактивність на JS передбачена на 2-му етапі (Final Demo).
